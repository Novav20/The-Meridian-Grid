### 1. Ubiquitous Language

- **Term**: Substation Configuration Description (SCD) File
- **Definition**: A text file created using substation configuration language (SCL) in XML format that contains the description of primary equipment, its location, connections on the main electrical diagram, control and protection functions, and signals.
> **Evidence**: "The SCD file is a text file created using substation configuration language (SCL) in the XML format. It contains the description of the primary equipment, its location, and connections on the main electrical diagram, as well as control and protection functions and signals." (p. 872)

- **Term**: Conventional Graphical Symbols (CGS)
- **Definition**: Graphical representations of equipment connected according to the main electrical diagram, whose visual properties change based on input signals from associated equipment.
> **Evidence**: "Typically, mnemonic diagrams are generated using conventional graphical symbols (CGS) of the equipment, connected according to the main electrical diagram of the electrical installation." (p. 872)

- **Term**: Mnemonic Diagram
- **Definition**: Main elements of automated workstations that display the primary equipment and operating conditions of an electrical installation.
> **Evidence**: "The main AWS elements include mnemonic diagrams, which display the equipment of the operating conditions of the primary equipment." (p. 872)

- **Term**: SyTrack SCADA System
- **Definition**: A SCADA system developed by DEP Company that utilizes SVG format for describing mnemonic diagrams and dynamicizing their elements based on signal connections.
> **Evidence**: "This format is used for describing mnemonic diagrams and dynamicize their elements based on signal connections in the SyTrack SCADA system." (p. 872)

### 2. Domain Rules and Invariants

- **Rule**: Dual-File Mnemonic Diagram Representation Rule
- **Mechanism**: Each mnemonic diagram in the SCADA system is stored as two distinct files: an SVG file describing the graphical sketch and an XML file mapping graphic element properties to real-time signal values from IED servers.
> **Evidence**: "In the SyTrack SCADA system, the description of each mnemonic diagram is stored in two files. The first file (in SVG format) contains the graphical sketch of the mnemonic diagram. The second file (in XML format) contains the mapping of the properties of graphic elements to the values of signals received from the server, which collects signals from IEDs associated with the equipment." (p. 874)

- **Rule**: Signal-Driven Element Dynamization Rule
- **Mechanism**: Visual properties of graphic elements (such as fill color, stroke, and visibility) are programmatically modified when associated signal statuses change in real-time.
> **Evidence**: "The dynamization of mnemonic diagram elements occurs when there is a change in the status of signals associated with technological processes. Such signals are linked to the properties of graphic elements (e.g., color, visibility, value, etc.)." (p. 873)

- **Rule**: Unique SVG Block Identifier Generation Rule
- **Mechanism**: Every SVG drawing block must possess a unique identifier programmatically derived from equipment, bay, and switchgear designations in the SCD file to enable precise signal binding.
> **Evidence**: "It should be noted that the SVG drawing blocks must have unique identifiers, which can be generated by the program based on the designations of equipment, bays, and switchgear." (p. 874)

### 3. Architectural Constraints and Patterns

- **Constraint/Pattern**: SCL-Driven Mnemonic Diagram Synthesis Pattern
- **Implication**: Mnemonic diagrams and signal bindings are automatically generated from IEC 61850 Substation Configuration Language (SCD) files, replacing manual graphical drawing and manual variable mapping.
> **Evidence**: "The algorithm is implemented based on the substation configuration description file, compiled in accordance with IEC 61850. The description of mnemonic diagrams is generated using the standard computer graphics format (SVG) based on conventional graphical symbols intended for the SyTrack SCADA system developed by the DEP Company." (p. 871)

- **Constraint/Pattern**: Two-Stage Automated HMI Generation Topology
- **Implication**: The generation pipeline enforces a strict decoupling between synthesizing the static layout sketch (placing CGS templates via topological graph analysis) and binding variables for visual dynamization.
> **Evidence**: "To automate the process of generation of mnemonic diagrams, the following two tasks can be conditionally identified: making a sketch of the static part of the mnemonic diagram and linking its elements to variables for dynamization." (p. 873)

- **Constraint/Pattern**: Hierarchical Model-Tree Project Management Constraint
- **Implication**: Diagram generation scopes and levels of graphic detail are selected through a project tree directly reflecting the SCD file's hierarchical model structure.
> **Evidence**: "Mnemonic diagrams can be generated for different parts of the electrical installation: overview mnemonic diagram of the entire electrical installation, mnemonic diagrams of individual switchgear or bays. The selection of the desired level is carried out based on the project tree, which displays the structure of the SCD file (Fig. 5, left)." (p. 875)

### 4. Context Assumptions

- **Assumption**: Inclusion of Equipment Spatial Coordinates in SCD Files
> **Evidence**: "The substation configuration description (SCD) file, which includes information about the coordinates of primary equipment, can be used for the automated generation of mnemonic diagrams." (p. 875)

- **Assumption**: Governance by Industry Corporate Standards for Information Display
> **Evidence**: "The rules for graphical representation of information on AWS used by the power industry companies are regulated by a corporate standard, which is based on general rules for constructing electrical diagrams." (p. 872)
